GLOW & FORM — HANDMADE HOME ACCENTS WEBSITE

WHAT'S INCLUDED
- Responsive storefront (desktop + mobile)
- 30 product entries based on the uploaded 30-page PDF catalogue
- Product images rendered from the supplied PDF and lightly enhanced for web display
- Category filters, product search, shopping bag, quantity controls and subtotal
- WhatsApp order message builder
- No backend or database required

IMPORTANT SETUP
1. Open script.js.
2. Replace WHATSAPP_NUMBER = "91XXXXXXXXXX" with your WhatsApp number, digits only.
3. Change the brand name, copy and contact details in index.html if needed.
4. Open index.html through a local static server for fetch(products.json) to work.
   Example: python -m http.server 8000
   Then visit http://localhost:8000

PRODUCT DATA
- Edit products.json to change product names, prices, categories or image paths.
- Prices are copied from the catalogue pages; please verify before publishing.
- Brand name "Glow & Form" is a temporary design name and can be changed.

IMAGE NOTE
The product photos are sourced from the PDF pages. The web presentation, crop, colour tuning,
layout and product-card treatment have been refreshed. The original catalogue lettering may
still be visible inside some source photos; those are not represented as website text.
